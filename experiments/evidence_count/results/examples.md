# Example prompts

Long blocks of neutral padding are shortened below.

LLM system prompt (all non-reasoning LLMs, numeric readouts): `Respond with one number only. Do not explain or show calculations; answer in a single step.`  
Yes/No readouts (yes/no decision, per-clue): `Respond with one word only. Do not explain or show calculations; answer in a single step.`  
max_tokens 20, temperature 0. Sonnet 5 reasoning: no system prompt, max_tokens 6000.

```text

```
